# Vida Psychotherapy, Counselling and Vocational Services

A responsive multi-page website for a counselling and vocational support practice.

## Pages
- Home
- About
- Services
- Contact

## Run locally
From this folder, run:

```bash
npx --yes serve -l 3000
```

Then open: http://localhost:3000/index.html

## Files
- `index.html` — home page
- `about.html` — counsellor profile and Psychology Today link
- `services.html` — services and process overview
- `contact.html` — enquiry form and contact details
- `styles.css` — responsive styling
- `script.js` — mobile navigation and form interaction
